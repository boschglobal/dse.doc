# Dynamic Simulation Environment

Welcome to the **Dynamic Simulation Environment (DSE)** documentation.

DSE is a message-based distributed simulation platform for building and integrating compositional simulations.

## Project Repositories

The Dynamic Simulation Environment is developed as a collection of open-source projects.

- 🧩 **[dse.clib](https://github.com/boschglobal/dse.clib)** — C-based implementation of the Dynamic Simulation Environment.

- 🔌 **[dse.fmi](https://github.com/boschglobal/dse.fmi)** — FMI integration and simulation support.

- 🧠 **[dse.modelc](https://github.com/boschglobal/dse.modelc)** — ModelC runtime, model interfaces, and tooling.

- 🌐 **[dse.network](https://github.com/boschglobal/dse.network)** — Network and communication support for DSE simulations.

- 📋 **[dse.schemas](https://github.com/boschglobal/dse.schemas)** — Schemas used across the DSE ecosystem.

- 🛠️ **[dse.sdp](https://github.com/boschglobal/dse.sdp)** — Simulation Development Platform and development workflows.

- 📐 **[dse.standards](https://github.com/boschglobal/dse.standards)** — Standards and API definitions for DSE.
