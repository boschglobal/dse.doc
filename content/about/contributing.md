**Contributing**

Contributions to the Dynamic Simulation Environment are welcome.

Each project repository may have repository-specific contribution instructions. For changes to the documentation or DSE projects, the general workflow is to open an Issue or Pull Request in the relevant repository.

**Before contributing**

- Check the documentation and existing issues for related work.

- For larger changes, discuss the proposed approach before implementation.

- Follow the contribution and development instructions of the repository you are changing.

**Pull Requests**

Keep changes focused and provide enough context for reviewers to understand the purpose of the change.

For documentation changes, please verify the affected pages and links locally before opening the Pull Request.

**DSE Projects**

DSE is developed across multiple open-source repositories under the BoschGlobal GitHub organization.

For an overview of the DSE-related repositories, see:
